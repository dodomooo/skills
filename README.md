# Skills

Claude Code plugin for skills development and documentation generation.

## Structure

```
├── .claude-plugin/
│   └── plugin.json          # Plugin entry point
├── commands/                 # Custom commands
├── agents/                   # Sub agents
├── skills/                   # Skills functionality
│   └── req-doc-generator/   # Documentation generator skill
├── hooks/                    # Hook scripts
└── servers/                  # MCP servers
```

## Usage

This plugin provides Claude Code with skills and commands for documentation generation and other development tasks.
